Panduan Mudah Mengirim Tugas via Google Drive

Ikuti 4 langkah sederhana ini agar link tugas Anda dapat dibuka dan dinilai oleh Guru.

1
Upload File ke Drive

Buka aplikasi Google Drive di HP/Laptop, lalu unggah file tugas Anda.

2
Ubah Akses Link

Klik titik tiga pada file → Bagikan → Ubah Akses Umum menjadi "Siapa saja yang memiliki link".

3
Salin Tautan (Copy Link)

Tekan tombol "Salin Link" (Copy Link) pada Google Drive Anda.

4
Kumpulkan di Web Ini

Klik tombol Kumpulkan Tugas di atas, tempel link, lalu kirim.

Pusat Bantuan & FAQ

Temukan jawaban untuk pertanyaan umum seputar penggunaan portal pembelajaran, pengumpulan tugas, dan masalah teknis lainnya.

Pertanyaan yang Sering Diajukan

Bagaimana jika saya salah memilih kelas saat login?
Anda dapat mengklik tombol "Keluar" (Power Icon) di pojok kanan atas, lalu login kembali dengan kelas yang benar. Hubungi Admin (Guru Informatika) melalui tombol WhatsApp agar data login Anda yang salah sebelumnya dihapus dari sistem.
Kenapa tugas saya terkunci dan tidak bisa dikumpulkan?
Tugas hanya akan terbuka jika tingkat kelas saat Anda login cocok dengan target kelas yang dibuat oleh Guru. Selain itu, jika batas waktu (countdown) sudah habis, tugas akan otomatis terkunci dan Anda tidak dapat mengirim link jawaban lagi.
Apakah tautan Google Drive saya aman?
Ya. Pastikan akses Google Drive diubah ke "Siapa saja yang memiliki link" (Anyone with the link) khusus untuk file tugas yang akan dinilai. Anda tidak perlu membagikan seluruh isi Drive, melainkan hanya file tugas yang spesifik tersebut.
Bagaimana cara mendapatkan XP atau Level?
Poin XP Anda bertambah setiap kali Anda mengirimkan tugas dengan sukses ke dalam sistem. Fitur lencana (badges) dan leaderboard siswa saat ini sedang dalam tahap pengembangan untuk memotivasi keaktifan kelas.
Masih butuh bantuan?

Tim pengajar dan admin siap membantu Anda mengatasi kendala teknis LMS.
