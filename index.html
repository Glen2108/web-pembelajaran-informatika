Panduan Mudah Mengirim Tugas via Google Drive

Ikuti 4 langkah sederhana ini agar link tugas Anda dapat dibuka dan dinilai oleh Guru.

1
Upload File ke Drive

Buka aplikasi Google Drive di HP/Laptop, lalu unggah file tugas Anda.

2
Ubah Akses Link

Klik titik tiga pada file $\rightarrow$ Bagikan $\rightarrow$ Ubah Akses Umum menjadi "Siapa saja yang memiliki link".

3
Salin Tautan (Copy Link)

Tekan tombol "Salin Link" (Copy Link) pada Google Drive Anda.

4
Kumpulkan di Web Ini

Klik tombol Kumpulkan Tugas di atas, tempel (*paste*) link, lalu kirim.
